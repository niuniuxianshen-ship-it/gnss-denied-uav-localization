# 订阅版开发试跑

本版调用已经登录 ChatGPT 的官方 Codex CLI，使用订阅 Codex 额度，不使用 API 密钥、不调用旧版付费 API 脚本。超过订阅额度时停止，不自动购买额度或切换 API。

输入为匿名图片、统一附录以及 A/B/C 提示词，均从前一版复制且不改内容。输出为首次可见回答、JSONL 事件、错误信息、用量（若 CLI 返回）、耗时、输入哈希与实际命令。脚本不会读取认证令牌或把密钥写入文件。

## 操作

在本目录打开终端，先检查：

```powershell
python -B run_trial.py
```

这只查看 CLI 版本、登录状态与输入配置，不发送模型任务。登录检查失败时自行执行 `codex login`，使用 ChatGPT 登录，不选择 API key。

确认后运行一次：

```powershell
python -B run_trial.py --run
```

此命令最多进行三次独立 Codex 会话，消耗订阅额度。固定 `gpt-6.1-sol` 与 low 推理强度；若账户不允许此模型则保留失败，不自动换模型。结果在新的 `runs/日期时间/` 下。

## 公平性和隔离

- 使用同一图片和附录，保持原 A/B/C 提示词内容。
- 全新 ephemeral 会话，不延续当前聊天；忽略个人用户配置，强制 OpenAI provider 和 ChatGPT 登录，去掉子进程中的 API key 环境变量，不修改全局设置。
- 请求禁用搜索、命令执行工具、插件和多代理，关闭既有记忆注入及生成；将 AGENTS 文档读取预算设为 0。本机 CLI 0.160.1 实测忽略 `tools.view_image` 设置，现已移除该无效设置，不声称本地图片查看工具被关闭；必须检查真实工具事件。
- 枚举已安装技能文件夹并传入禁用覆盖，只读取路径、不读取技能正文。运行目录只放匿名图片，不放标准答案或准备记录。
- 临时运行目录仅用于避免项目文件自动注入，不是操作系统级文件访问隔离；仍需检查真实事件和错误日志，不能仅凭设置声称绝对无工具。
- CLI 自带基础系统提示和受管理配置仍可能影响输出，服务端参数也不等同于直接 API。输出 token 上限沿用 CLI 默认，未声称固定为 API 版的 4096。图片 detail 未通过 CLI 参数固定。
- 本运行器不自动重跑；CLI 自身可能重试传输，应检查事件和日志。首次开发顺序 A/B/C 固定，多图正式实验前另定交错顺序。
- 不与 API 版合并统计，不自动评分。配置警告与传输重连单独记录，不等同于工具调用；`turn.failed`、未完成、空输出或意外 item 类型记录后停止。顶层 error 可能是恢复后的重连，也可能是其他错误，必须人工检查日志，不能因收到 turn.completed 就忽略警告。

## 本轮任务和验收

30—60 分钟：完成默认检查，再完成一张开发图的三版本运行；将 `summary.json` 和三份文本输出交给导师。首次结果不可用后续“最好的一次”替换。

验收：输入哈希一致、同一模型请求、三个独立会话、输出完整、无额外工具事件；若隔离无法确认，记录限制。本轮只检验流程，不证明准确率或可靠性提高。

已经确认本机 CLI 存在且登录状态为 ChatGPT；尚未进行真实模型试跑，账户模型权限与效果仍待检查。默认检查和模拟事件验证通过后在验证记录中报告。
