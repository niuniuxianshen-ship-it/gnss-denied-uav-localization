# 视觉定位方法论

给一张图片，判定拍摄位置。本技能是一套**离线视觉定位协议**：定位期间不联网、不搜图、不查图，信息源只有三项——图片本身的观察、本技能的速查表、模型内部地理常识。当前版本主攻**中国境内**定位（文字类线索密度高，可稳定到省/市，理想情况到县）；世界图方法保留为扩展章节（第五章）。

输入类型：街景全景图（百度街景等）、普通户外照片、行车记录仪/监控截图、视频帧。

**可信度标注约定**（贯穿全文）：
- **事实**：官方规则或国家标准，可直接依赖（如国道编号规则）。
- **主流观点**：社区/常识共识，命中率高但非 100%（如某省常见民居样式）。
- **推测**：经验性启发，仅作辅助。

来源见文末「参考资料」。世界图部分改写自 PlonkIt Beginner's Guide（CC BY-NC-SA），仅限个人学习使用。所有速查表均离线可用。

## 一、定位总流程（五步）

1. **全局吸收（约 10 秒）**：转一圈看大环境——气候带（植被茂密？荒漠？雪原？）、地形（平原/山地/喀斯特）、道路等级（高速/国道/村道/城市街道）、画面视角（地面平视/航拍/远景）。
2. **定大区**：用第一层硬线索收窄。线索优先级：**可读文字（路牌/招牌/车牌）> 双语文字 > 车牌配色 > 行驶方向 > 街车与画质 meta > 植被气候 > 建筑地形**。文字是唯一"确定性"线索，其余是概率。
3. **收硬线索**：变焦读小字——路牌地名、国道/高速编号、电话区号、车牌简称字母、门牌、公交站牌、店招。中国图里这些几乎能直接定位到市、县。
4. **缩小到省/市**：用车牌字母、区号、国道桩号、植被农作物、民居样式收窄（第三章速查）。
5. **落点估计**：综合所有线索给出坐标估计（用第四章锚点表推算），并给出精度等级（省/市/县级）。**离线定位不做地图比对**，用 2.5 的内部知识校验法自检。

**保底原则**：每张图都必须有结论。把握不足时，把落点估计放在候选区域几何中心，并在报告里如实标注低置信。

## 二、离线视觉定位协议

### 2.1 模式与三禁

定位期间：
1. **禁联网**：不搜索图片、不搜地名、不查攻略、不反向搜图。
2. **禁查图**：不查任何地图、卫星影像、街景图库做对照校准。
3. **禁假装**：没做过的校验不得声称做过（如"对照卫星图确认了"）；读不清的文字不得编造。

**允许的信息源仅三项**：图片本身的观察（放大、平移截图均属本地操作，不违反三禁）；本技能全文（各章速查表与方法论，均离线可用）；模型内部地理常识（邻省关系、气候带、走廊走向）。若用户明确要求联网核对，先出完纯视觉定位报告，再另行核实并注明"该步骤已非纯视觉定位"。

### 2.2 八步扫描 SOP

按固定顺序扫图，每步记录"看到了什么/什么看不清"：
1. **天空与光影**：阴影方向、长短 → 半球与纬度带（见 3.1 / 5.1）。
2. **道路与行驶方向**：左行/右行（见 5.2）；道路等级、标线样式。
3. **文字**：路牌、招牌、门牌、广告——先找最大最清晰的；读不清就如实标注"不可读"，绝不猜字。
4. **车辆**：车牌颜色与字符（完整可读 = A 级线索，见 2.3）、车型与年代感。
5. **设施**：电线杆样式、护栏桩、路牌版式、井盖。
6. **植被与地面**：对照气候带-植被带表（见 4.4 / 5.5）定植被带；识别农作物。
7. **建筑与地形**：屋顶形式、民居样式、山形地貌。
8. **相机与街车**：画质、相机特征、采集车样式（百度街车见 3.3；谷歌街景 meta 见 5.3）。

**视角退化分支**（实测补充）：对象缺失时按可用步骤执行并主动降精度，不要硬凑。夜景：跳过第 1/6 步，靠店招灯箱与建筑形制；航拍/天际线视角：跳过第 2/4/5 步，改用城市形态（高层密度、路网纹理）、植被、地形；远景无车无文字：精度止步省/国级，按植被带+地形收敛，报告里写明"线索不足"。

### 2.3 线索置信度分级

- **A 级（可确认）**：完整可读的车牌、地名、电话区号、高速编号+简称、国名路牌。出现 A 级即可给"确认结论"。
- **B 级（强推断）**：文字体系与语言归属、双语类型（民族文字）、行驶方向、相机/画质特征、街车特征、**地标建筑与天际线辨识**（须注明"凭 landmark 知识"，警惕相似形制，见 3.2 易混淆对）。仅 B 级时给"高置信推断"。
- **C 级（倾向）**：植被带、建筑民居样式、地形、品牌分布。仅 C 级或以 C 为主时给"低置信估计"，落点用区域中心。

裁决规则：A 与 B/C 矛盾时降级处理，在报告中列出矛盾点；同类 C 级线索互相印证可升为"中置信"；任何结论至少要能说出一条图内证据。**两条线索冲突时按确定性排序取信：可读文字 > 行驶方向（二值事实）> 街车与画质（强概率）> 植被建筑（弱概率）。**

### 2.4 定位报告模板

默认输出格式（用户只要一句答案时，可压缩为"结论+置信度+两条依据+落点"）：

```
【定位报告】
- 确认结论：……（仅有 A 级线索时才写此行）
- 推断结论：……（置信度：高/中/低）
- 依据：① 观察到的线索 → 对应速查条目；② ……（逐条列出）
- 第二候选：……（区分线索：……）——精度等级为市级及以上时必填，防止"唯一假设"过拟合
- 落点估计：约 （经度E, 纬度N）（参照 4.4 锚点推算）
- 精度等级：国 / 省 / 市 / 县级
- 不确定点：……（哪些线索缺失或矛盾，补齐什么可升级结论）
```

### 2.5 无地图校验替代法（三禁下如何自检）

- **邻域常识校验**：结论落定后，检查邻省是否与全部线索一致——例如定为西安附近，就应见关中平原景观与面食店招；若同时出现椰林，说明结论错误，回炉。
- **方位一致性校验**：影子方向与推断纬度带是否一致（3.1）；临海方向与推断位置是否一致（如结论在广西内陆却见大海，推翻）。
- **走廊定位**：高速/国道编号+简称（4.3）给出两端城市，桩号增减与植被序列估计在走廊中的相对位置。
- **气候带定位**：植被带（4.4）→ 候选纬度带 → 与影子方向互验。
- **排除留痕**：报告中写明排除了哪些候选、依据什么排除，便于复盘与纠错。

## 三、中国定位专项

中国大陆街景主要采用百度街景（主流观点）。中国图信息密度高：**文字类硬线索几乎能定位到市**，推理顺序是"先文字、后景观"。

### 3.1 硬线索：文字与编号

**车牌**（事实：车牌规则为国家标准，字母分配官方确定）：
- 配色：蓝牌=普通燃油小车；绿牌=新能源（渐变绿为小型、黄绿为大型）；黄牌=大车/挂车/部分摩托；白牌=警车等特种；黑牌=使领馆等。绿牌大量出现 → 拍摄年代较新（2017 后）。
- 格式"省份简称 + 发牌机关字母"。A = 省会/直辖市（全表见 4.1）；主要省份 B 城见 4.1。牌照清晰时这是第一优先线索：**简称定省，字母定市，一秒完成区域定位**。

**电话区号**（事实，固话区号长期稳定）：出现在店招、公交车体、宣传牌上。大区中心：010 北京、020 广州、021 上海、022 天津、023 重庆、024 沈阳、025 南京、027 武汉、028 成都、029 西安。省会区号表见 4.2。**区号 + 车牌双重验证**是标准动作。

**路牌与道路编号**（事实，依据国标 GB/T 917 等）：
- 指路牌配色：绿底白字=高速公路；蓝底白字=一般道路；黄底=警告。
- 国道 G1xx 为北京放射线、G2xx 南北纵线、G3xx 东西横线；省道 S、县道 X。里程碑写作"G210 K2534"——**编号查路线走向，桩号定相对位置**。
- 高速编号+名称双线索：名称=起点首字+终点首字（京沪、连霍、沪昆、沈海……），主干线速查见 4.3。
- 路牌地名、乡镇界碑、公交站牌线路名、快递网点名、"XX县人民医院"类招牌——任何可读地名直接定位。

**双语路牌 → 民族地区映射**（事实：双语标识按民族自治地方规定）：
- 蒙古文（竖排）→ 内蒙古；藏文 → 西藏/青海/川西/甘南/滇西北；维吾尔文 → 新疆；朝鲜文 → 吉林延边；壮文（拉丁字母）→ 广西；彝文 → 四川凉山/云南北部；傣文 → 西双版纳/德宏。
- 繁体+港式用字 → 港澳。

### 3.2 区域判断：南北方与省份景观

先按"秦岭—淮河"一线分南北（主流观点），再用下表特征交叉：

| 线索 | 指向南方 | 指向北方 |
|---|---|---|
| 农田 | 水田、梯田、一年两熟 | 旱地小麦/玉米、一年一熟、地垄宽 |
| 村居 | 坡顶瓦房、天井、骑楼 | 平顶/红砖房、火炕烟囱、苞米楼子（东北） |
| 行道树 | 樟树、榕树、棕榈 | 杨树、柳树、国槐、银杏 |
| 地貌 | 丘陵、喀斯特峰林（桂黔滇） | 大平原（华北/东北）、黄土塬梁峁（陕晋） |

**标志性组合**（主流观点，命中即可强定位）：
- 骑楼街道 → 两广/海南/闽南；土楼 → 闽西南；徽派马头墙 → 皖南/赣北；海草房 → 胶东半岛；窑洞 → 陕北/晋西/豫西；吊脚楼 → 湘西/黔东南/渝东南。
- 藏式碉房+白墙+经幡 → 藏区；蒙古包/砖包+草原 → 内蒙古；馕坑+平顶土房+杨树防护林 → 新疆绿洲。
- 橡胶林/椰子林 → 海南、滇南；茶园连片丘陵 → 浙闽湘滇川；青稞+高山 → 西藏；向日葵+沙地 → 内蒙古/新疆；胡杨 → 塔里木盆地。
- 喀斯特峰林 → 广西/贵州/云南东部；火山地貌 → 五大连池/腾冲；戈壁风蚀 → 甘新。

**易混淆对与鉴别**（实测迭代补充，主流观点）：仿唐文旅街区：西安 vs 洛阳——看步行街轴线尺度、灯组风格与店招全文；俄式东正教堂：哈尔滨（老城商业广场环绕、俄式老建筑群）vs 满洲里（中俄双语+俄文招牌、口岸风貌）vs 内地零散东正教堂（多为孤立文物点）。

### 3.3 街景来源与街车特征（进阶）

- 百度早期街景由**三轮车**采集，常见于胡同/老城窄巷，多对应大城市早期覆盖（主流观点）。
- 不同城市/时段的百度街景**车型、天线、色彩风格不同**，熟练后可做城市级判断；这是高阶技巧，先掌握区域判断再学（推测→社区经验）。
- 路桩、隔离栏、红绿灯样式城市间有差异，可作辅助（社区经验）。

### 3.4 太阳方位（中国图）

中国绝大部分位于北回归线以北（事实）：正午太阳在正南、影子朝北。结合指南针：影子朝向西北→时间偏下午且纬度较高；结合影子长度与季节估纬度带。海口/三亚等低纬注意例外。**正午影长-纬度定量近似**（推测级，春分/秋分前后最准；夏短冬长按季节修正）：影长/物高 ≈0.2→10°；≈0.36→20°；≈0.58→30°；≈0.84→40°；≈1.0→45°；≈1.7→60°。游戏外可用"人影约为身高几倍"目测。经度粗判：同日同时刻太阳越偏西经度越靠西（新疆正午光影比东部晚约 2 小时），仅作大区辅助（推测）。

### 3.5 城市级辅助线索（抓到一个就能跳过省级判断）

- 银行/农信招牌通常含行政区划名（如"陕西信合"类农信品牌、"XX农商行/城商行"）——接近事实级的地名线索。
- 公交站牌（线路名+站名）、出租车门徽与监督电话（常含区号）、快递网点名、外卖柜、共享单车（各城市投放品牌与覆盖年代不同——主流观点）。
- 加油站品牌分布南北有差异（中石化南方更密、中石油北方更密——主流观点，弱线索）。
- 店招菜系与用字（面馆/米线/烧腊/徽式匾额）、方言地名用字（"坳、塘、屯、堡、甸"）——推测级，只作倾向。
- **屋顶真空管太阳能热水器**（一排排亮闪闪的真空管）+卫星接收锅：大量出现 → 中国大陆城乡结合部/县城/农村（主流观点；海外几乎不用真空管式）。

## 五、世界图扩展方法（当前为辅助章节）

### 5.1 太阳与半球

街景自带指南针时：**影子方向 ≈ 背离太阳**——正午影子朝北 → 太阳在南 → 北半球中高纬；影子朝南 → 南半球。**南北回归线之间不适用**此推断（事实），热带靠植被、文字、街车定。普通照片无指南针时，用太阳高度+拍摄时刻反推（推测级）。影长-纬度换算见 3.4。

### 5.2 行驶方向

**左行主要国家/地区**（主流观点，全表见 PlonkIt）：英国、爱尔兰、日本、泰国、印尼、马来西亚、新加坡、文莱、东帝汶、印度、巴基斯坦、孟加拉、尼泊尔、斯里兰卡、澳大利亚、新西兰、南非、肯尼亚、乌干达、坦桑尼亚、莫桑比克、赞比亚、津巴布韦、博茨瓦纳、纳米比亚、马耳他、塞浦路斯、中国香港、中国澳门。世界约 3/4 国家右行——"左行"是强线索，"右行"信息量低。

### 5.3 相机与街车 meta（谷歌街景）

- **相机代数**（主流观点）：Gen 2——画面底部与天空有圆形模糊带；Gen 3——低饱和、天空发灰；Gen 4——高饱和鲜艳。画质奇差（shitcam）常见于印度、尼日利亚、柬埔寨、黎巴嫩、厄瓜多尔等；瑞士、日本部分、列支敦士登、斯里兰卡为低相机。
- **特色街车**（主流观点，示例）：肯尼亚灰色皮卡带通气管；吉尔吉斯斯坦车顶架+后视镜改装；俄罗斯黑车长天线（Gen 3）；阿根廷 Gen 3 黑车可见车尾；玻利维亚/智利/秘鲁常见 Gen 3 白车。小国与领地几乎必有独有街车。
- **季节 meta**：有些国家只在一个季节覆盖过（如吉尔吉斯斯坦 10-12 月拍摄似冬景）。看到"反常季节"先想覆盖季节而非真季节。
- **假 meta 概念**：任何单一特征都可能有反例。**≥2 条独立线索交叉验证后再落国家**。

## 六、常见误区

- **单线索定结论**：一种树、一种车就下结论——必被假 meta 反噬。
- **忽视画质与季节**：把"覆盖季节的雪"当成"当地冬季气候"。
- **文字线索没读透**：变焦不够就放弃小字；中国图里一块路牌往往就够定位到县。
- **只给唯一假设**：市级及以上结论没有第二候选和区分线索（见 2.4 模板要求）。
- **谷歌街景经验照搬百度街景**：百度没有相机代数体系，要用区号/车牌/双语路牌这套本土线索。
- **虚假校验**：声称"对照了地图/卫星图"而实际没有（违反 2.1 三禁）；或把锚点推算坐标当精确坐标报告。

## 七、报告范例

**范例一（中国图，有 A 级线索）**
画面：蓝底路牌、蓝牌车"云A"、樟树行道树、坡顶瓦房、路牌无民族文字。

```
【定位报告】
- 确认结论：中国云南省昆明市附近
- 依据：① 车牌"云A" → 云=云南、A=省会（4.1）→ 昆明；② 樟树+坡顶瓦房印证滇中（3.2）；③ 路牌无民族文字 → 非自治州边境（3.1）
- 第二候选：云南省曲靖市（区分线索：需读到区号 0874 或路牌地名才能区分）
- 落点估计：约 (102.7E, 25.0N)（4.4 昆明锚点）
- 精度等级：市级
- 不确定点：无街道名可读，无法到县级
```

**范例二（中国图，航拍无文字）**
画面：华北平原县城航拍，大转盘+纪念碑，白瓷砖老住宅楼，杨树行道树，平原无山。

```
【定位报告】
- 推断结论：华北平原/黄淮平原某县级市（豫东/鲁西/皖北/苏北一带）（置信度：中）
- 依据：① 一马平川无山+杨树+白瓷砖楼 → 华北/黄淮平原县城（3.2，C 级）；② 规整大转盘+宽大道 → 2000 年代新城面貌（C 级）；③ 植被茂密夏季 → 暖温带（4.4）
- 第二候选：河北平原县城（区分线索：需店招文字或车牌，此图不可读）
- 落点估计：约 (115.0E, 34.0N)±1.5°（4.4 郑州锚点东北方向推算）
- 精度等级：省区域级（线索不足，按 2.2 视角退化分支降级）

```

## 八、技能自评与迭代

**盲测自评流程**（迭代本技能时用）：取材 → 脚本随机抽图（答案只写进文件、屏幕不显示）→ 先出定位报告再对答案 → 错因三分类：**数据源问题**（非街景视角）/ **技能缺口**（缺速查表或分支）/ **模型误判**——只有第二类需要改技能。
- **素材有效性先验**：中文图片搜索对"街道/街景"类查询极易返回宣传航拍、地图、模板图——先确认素材是街景级照片再评分，无效素材作废。
- **可用素材渠道**（2026-10 实测）：百度全景静态图 API（需个人 AK 且开通服务，坐标可全盲）；用户自行截图（城市已知、画面内容盲）；中文图片搜索（成功率低，图库垃圾多）。谷歌街景在当前网络环境不可达，世界图实测受限。
