# DeepSeek 开发图试跑

本运行器专门适配 DeepSeek Chat Completions，不调用 Codex CLI。默认只进行离线检查，不读取凭据或调用模型。正式运行使用官方 API 额度。

## 接口逐项核对

核对日期：2026-10-09。来源：[Chat Completions API](https://api-docs.deepseek.com/api/create-chat-completion/)、[Vision](https://api-docs.deepseek.com/guides/vision/)。文档支持不等于账户实测，实际接受情况以首次响应为准。

|项目|适配方式|核验范围|
|--|--|--|
|端点及认证|POST `https://api.deepseek.com/chat/completions`；Bearer DeepSeek key|与订阅 CLI、OpenAI Responses 分开；拒绝重定向|
|模型和图片能力|`deepseek-flash`；PNG 图片随 user 消息传入|官方文档明确图片输入；真实返回模型名另存|
|消息结构|每版只有一条 user 消息，两个 content 块：text、image_url|不传历史、会话 ID、当前对话、准备记录、清单、来源路径或完整技能|
|图片载荷|本地匿名 `001.png` 转 Base64 data URL；detail=original|字节哈希固定；CRC、解压和尺寸核验；只含 IHDR/IDAT/IEND；不使用外部图片 URL|
|大小限制|图片约15.8 MiB；JSON 请求约21.1 MiB|低于文档32 MiB内联单图及48 MiB请求限制；离线逐版检查|
|推理开关|thinking.enabled；reasoning_effort=low|DeepSeek字段逐项按文档设置；不声称与另一模型的low等价|
|输出预算及采样|max_tokens=4096；stream=false；text格式|temperature在思考模式文档说明无效，未发送；seed未发送、不可控|
|工具|不提供tools；tool_choice=none；运行器不执行任何返回工具调用|检查tool_calls、function_call、finish_reason；服务端隐藏行为未确认|
|解析|choices[0].message.content、reasoning_content、finish_reason、model、usage|首份原始JSON完整保存；正文、推理字段分别保存；不把推理字段拼入最终正文|
|截断|finish_reason不为stop即记录异常；length单独可见|不补发continue、不扩大预算重跑|
|重试及错误|标准库HTTP单次请求，每版最多一次；没有SDK隐式重试|HTTP/传输/响应结构错误保留并停止后续版；有效答错、拒答、格式错照常保留后继续|
|环境|无本地技能、记忆或文件工具接入；只读取固定输入文件|服务端共享记忆、隐藏指令、隐藏工具及图像处理未确认；不得称已隔离|

## 输入版本

图片和附录与先前开发输入字节一致，不扩充数据集，不增加梯田规则。A/B/C各自流程与格式保留，三版仅将旧的信息限制句统一换为：

> 三版均可依据画面中可见的信息、共同参考附录和模型已有地理知识进行判断，但不得联网、读取图片元数据或答案文件；模型已有地理知识不自动视为已验证事实，共同附录缺少相关条目也不自动构成必须拒答的理由。

本次提示词因此与旧GPT试跑不同，不宜直接归因于模型差异。三个提示词及共同输入作为复核交付物保留。

## 命令

在本目录：

```powershell
python -B .\run_trial.py
python -B .\run_trial.py --run
```

第二条需要当前进程环境变量 `DEEPSEEK_API_KEY`；也可用 `--key-env 变量名` 或 `--key-file 已有纯密钥文件路径`。不要在公开命令、脚本或记录中写密钥。运行器不保存凭据。

离线证据在 `离线检查.json`；真实运行在独立 `runs` 子目录，包括设置、输入正文、脱去Base64的请求审计、原始响应、正文、推理字段、summary.json及试跑记录.md。离线fixture只是解析检查，不是模型输出。
