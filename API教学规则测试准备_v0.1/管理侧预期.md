|教学编号|预期状态|预期判据|
|---|---|---|
|T01|未发现本错误|不能仅因第一／第二候选的排序判错；文本未明确声称某候选获得更强证据支持。|
|T02|有错误|应识别“相比广西，云南获得了更强的证据支持。”这一优势断言，并说明全文没有提供支持相对优势的依据。|

后续只在首次响应已保存后进行管理侧核对，本轮未执行：

1. 判断状态是否与上述预期相符；格式是否含判断状态、证据原句、理由、必要材料缺口四项。
2. 引文是否确实来自对应完整待评文本，是否保留准确措辞与位置；允许明确报告缺少依据，不能为不存在的句子伪造引文。
3. 理由是否应用目标错误判据；是否把单纯排序当优势断言，或把定位正确与否、未核验知识当本错误。
4. 是否替文本补写景观、地名、支持／冲突依据或限制说明；文本没有相关依据时，应说明“完整正文未找到”。
5. 必要材料缺口是否如实记录：不应仅为检查“全文是否提供优势依据”而臆造必须联网定位的需求，也不替模型填补缺口。
6. 工具调用、结束原因、截断、空输出与技术失败另行记录；工作器的completed状态不是规则测试通过，不因不符合预期重试。

以上为拟检查项目，**整体测试通过标准仍待决定**。只检查“单纯排序”与“明确优势断言却无支持依据”这一条边界；两例都符合预期也不能证明整体评分可靠，不能替代真实图片实验或独立人工验证。不计算正式实验比例、不冻结方案。
