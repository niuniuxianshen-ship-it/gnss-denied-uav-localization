# 离线文本组装 v0.1：教学准备

本目录仅准备教学文本草案，不是研究样本或实验结果。四项任务均为“尚未调用”。本轮只读取指定任务清单、清单中两张图片及两个提示词文件、指定附录，共六个不同输入文件；未读取清单中的配置文件引用，也未扫描其他研究材料。文本文件全文读取，图片以完整二进制文件读取并计算哈希，不进行视觉定位或转写。

## 文件与组装规则

- [assemble_texts.py](assemble_texts.py)：Python标准库离线入口。
- [check_assembly.py](check_assembly.py)：可重复离线核查，临时文件仅创建于本目录并自动清理。
- [组装清单_管理用.json](教学文本草案/组装清单_管理用.json)：登记原任务编号、图片路径与哈希、提示词和附录路径与哈希、文本路径与哈希；管理清单不属于待输入正文。
- 四份正文见下表。文件名及管理清单将它们标为教学草案，正文不增加教学标签或管理说明。

每份文本严格为：提示词原始字节 + `b"\n\n"` + 附录原始字节。不去除原文末尾换行，不统一换行格式，不增加任务编号、管理信息、图片来源、参考答案或评分标准。本次提示词本来以一个LF结束，再插入两个LF；附录原有CRLF换行完整保留。附录全文及“未核验”声明逐字节保留。

图片保持原位，不嵌入或转换为文字。两张图片使用同一条件时文本完全相同，因此01与03、02与04的文本哈希相同；它们仍是四个不同任务，图片对应关系以管理清单为准。

## 使用与实际离线核查

本机实际使用Python 3.10.0，无第三方依赖，其他版本未验证。在本目录执行：

```powershell
python -B .\assemble_texts.py --manifest '..\批量入口离线准备_v0.1\教学任务清单.json' --appendix '..\开发输入\参考附录正文.md' --output-dir '.\教学文本草案'
python -B .\check_assembly.py
```

第一条为本轮实际首次组装命令，退出码0，生成4份文本及1份管理清单。交付后再次运行同一组装命令会以退出码2拒绝，因为输出目录已存在；即使目录为空也拒绝覆盖。要重新组装，应显式使用本目录内一个未占用的输出子目录；本轮未执行其他输出位置。

入口只读取显式清单中的图片及条件文件；相对输入路径以清单所在目录为基准。图片和提示词必须符合清单预期SHA-256，所有输入完成核验后才创建新输出目录。附录未在旧清单登记预期哈希，本轮记录实际读取哈希并在写入前复查，没有自行把附录认定为冻结材料。目录创建或写入发生异常时返回错误；若留下部分产物，需保留并另用新目录，入口不补写或覆盖。
