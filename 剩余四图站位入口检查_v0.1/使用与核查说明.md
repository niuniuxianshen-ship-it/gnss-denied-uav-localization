本目录保存001、002、007、019的一次有界公开入口检查，状态为材料收集完成、待导师审查。没有模型请求，不裁定入选，不冻结方案。

先读[四图材料提取表](/C:/Users/leimaren/Documents/Codex/2026-10-09/6-2-x20/outputs/视觉定位流程实验/剩余四图站位入口检查_v0.1/四图材料提取表.md)，再读[执行与访问记录](/C:/Users/leimaren/Documents/Codex/2026-10-09/6-2-x20/outputs/视觉定位流程实验/剩余四图站位入口检查_v0.1/执行与访问记录.json)及其中对应的工具返回。指定八份输入的全文读取和整理前哈希登记见[检查前记录](/C:/Users/leimaren/Documents/Codex/2026-10-09/6-2-x20/outputs/视觉定位流程实验/剩余四图站位入口检查_v0.1/输入原件哈希_检查前.json)；整理后结果见[输入原件哈希核查](/C:/Users/leimaren/Documents/Codex/2026-10-09/6-2-x20/outputs/视觉定位流程实验/剩余四图站位入口检查_v0.1/输入原件哈希核查.json)。

工具返回目录中每图两份JSON和两份TXT：第一次为说明页，第二次为同批的修订与讨论。JSON保留完整工具返回及调用参数、时间；TXT逐字保留同一返回字符串。修订和讨论同批的两对象只有共同起止区间，没有逐对象计时。成功取得网页转录不等于取得源站HTTP状态或HTML。四个讨论入口的404是工具报告，不能解释为内容不存在。原作品页的图像和元数据可能自动出现在转录中，没有被用于补写站位。

离线核查程序仅使用Python标准库，读取本目录和已明确登记的八份输入路径；不会联网、读取环境变量或凭据、启动旧运行器或API工作器。它核对输入哈希、四图与十二对象、每图8分钟上限、工具JSON和TXT字符串一致、引文存在及本地链接。它不裁定站位证据或资格，不刷新网页，也不重开例行追查。

在项目根目录启动：

```powershell
python -B ".\剩余四图站位入口检查_v0.1\离线核查.py"
```

首次离线结果保存命令：

```powershell
python -B ".\剩余四图站位入口检查_v0.1\离线核查.py" --report "离线核查结果.json"
```

本轮实际执行的是上面的保存命令，结果见[离线核查结果](/C:/Users/leimaren/Documents/Codex/2026-10-09/6-2-x20/outputs/视觉定位流程实验/剩余四图站位入口检查_v0.1/离线核查结果.json)；验收采用实际结果。再次检查请使用不带--report的命令，它只打印结果，不改档案。该不保存命令未单独执行；报告文件已存在时保存命令拒绝覆盖。程序不能复现源站未来的动态内容，只能复核本次归档。无需安装依赖；当前Python版本及实际结果在最终核查中登记。

未取得或未执行：源站原始HTTP响应/HTML，逐版修订正文，讨论正文，隐藏或非公开记录的穷尽检查，实际摄影者身份认证。019的location摘要已定位，内容解释仍待审查。所有模型调用数为0；无新增作品、联系作者、资格裁定或方案冻结。

本轮未创建一次性临时文件。保留核查程序、报告、首次工具返回、失败证据和哈希；后续发现新照片专属证据入口时先另行决定，不自动再访问这四图。
