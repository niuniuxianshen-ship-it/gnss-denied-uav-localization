## 使用与本批冻结门槛

本轮实际执行了明确的check命令及离线核查脚本；如下为只读检查和可重复离线核查用法：

```powershell
$entry = 'C:\Users\leimaren\Documents\Codex\2026-10-09\6-2-x20\outputs\视觉定位流程实验\关系记录新材料执行入口_v0.1'
python -X utf8 -B "$entry\run_comparison.py" check
python -X utf8 -B "$entry\check_offline.py"
```

程序无action参数时默认check，不生成请求、不写档案、不读取凭据、不联网。核查脚本不带--report只输出结果；本轮曾用`--report 离线核查结果.json`独占保存首次结果，再指定该同名文件将拒绝覆盖。不要删除首次报告来重建。

真实执行必须同时满足：显式run --execute-review；本批本地冻结登记及明确指定的SHA-256核对通过；配置、程序、请求与管理依据哈希一致；本入口下不存在运行档案目录或符号链接。只有这些检查通过才读取DEEPSEEK_API_KEY环境变量；不读凭据文件、不保存密钥或认证头。阶段目录使用独占mkdir预留，已存在则不执行、不续跑。

本轮**没有创建本批冻结登记.json，没有冻结模板或冻结命令**。未来确经另行审阅和授权后，登记须使用以下独立结构；这是接口字段约定，不是审批决定：

## 首次档案与停止规则

未来真实档案固定在本入口的运行档案目录：阶段stage_start.json、summary.json；各任务子目录保存attempt.json、实际request.json、原始response.json、可取得的完整output.txt及metadata.json。记录请求／返回模型、设置、开始结束及耗时、结束原因、用量、输入及载荷／响应哈希、失败与缺失文件。原响应即使不是合法JSON，也保留已取得字节；中断尽量保留部分字节，未取得的响应或正文不补造。

技术失败、空输出、截断、工具调用或必要响应字段／归档失败时保存可取得记录并停止后续，不重试、不切换模型。判断状态、比较关系表缺失、四字段格式偏差或文本拒答不由入口裁定，不触发重试；completed仅为技术状态。网络尝试标记不证明服务器已收到请求。独占档案目录即使只留下部分文件，也阻止重新执行或覆盖。准备关联表仍保留“尚未调用”的历史状态，未来实际进度另从首次档案查找。
