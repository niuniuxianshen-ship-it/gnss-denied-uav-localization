# 中国大陆地面照片省级定位流程实验

本项目比较三种视觉定位提示流程，研究模型如何从中国大陆地面照片判断拍摄地点所属的省级行政区，以及结构化线索、候选比较和拒答规则如何影响输出过程与结果。项目面向可理解、可复现、可评价的本科阶段研究练习。项目发起人的本科专业为测绘工程，计划于 2028 年 12 月参加导航或遥感方向研究生考试；这是项目背景，不是实验结论。

当前证据不足以判断 A、B、C 中哪一种更有效。本文区分已有单图开发试跑、人工编写的 CASE、模型对 CASE 的评分和真实图片正式评价；它们不能互相替代。

## 研究问题与方法

三种流程计划在同一批图片、同一模型和相同可控条件下比较：

|流程|要求|证据不足时|解释边界|
|---|---|---|---|
|A：直接判断|直接给出省级行政区和置信分数|仍须选择一个省|不能据此评价线索表达或候选比较|
|B：结构化线索|记录可见/不可读内容，区分观察与推断，列支持和冲突线索，再给省份|仍须选择一个省|增加了信息披露要求，但没有 C 的候选比较和拒答规则|
|C：结构化比较|记录线索，列有依据的省级候选，比较第一候选与其他候选，说明区分证据和冲突|主要候选无法区分或关键冲突未解决时可回答“无法判断”|与 A/B 的输出要求及选择规则不同，单一结果差异不能归因于“推理更好”|

真实图片设计指定 C-v2。A/B/C 的信息量、输出格式、候选要求和拒答政策不同；即使未来在小样本上出现数值差异，也不能单独证明结构化分析导致差异，更不能推出统计显著性、因果优越性或总体效果。模型给出的 0—100 置信分数只是模型自评原值，不是校准概率；目前没有校准分析。

研究设计及提示词依据见[真实模型评价实验设计 v0.1](真实模型评价实验设计_v0.1.md)，过程评分规则见[候选比较评分表 v0.2](候选比较评分表_v0.2.md)。

## 评价指标与数据安排

设计中的主要评价是输出过程质量，四项分开报告：流程/新增比较要求遵守、候选比较依据、证据不足处理、可核验的视觉线索真实性。每项拟由两个独立评分者按固定表记录；仅对双方均为有效 0—2 数字分的配对计算 `E/D`，并报告计划数、有效数、排除原因和状态分歧。不能看图核验时记未评，不因同分自动认定理由有效。

辅助评价在评分材料锁定后才由管理侧揭示参考标签：明确选择数、标签吻合数、拒答数、无效解析数和技术缺失分别报告；设计给出的比例包括 `N_correct/N_answer`、`N_answer/N_label` 和 `N_correct/N_label`。目前没有正式名单或本批输出，因此这些指标均尚无结果。10 张小样本只计划作开发集描述，不设成功阈值、不作普遍推广。拒答计入回答覆盖口径，不改记为错误地点。

标签来自具体照片与独立来源证据的逐图核查，标签管理员与过程评分者应分开。当前材料将“模型输入”“评分者材料”“管理参考答案”“原始来源/响应证据”分置于不同目录；这只是组织约定，不是系统权限隔离。发放前仍须逐批核对白名单、哈希、接触记录和内容，参考答案、标签、坐标、来源页及评分者管理文件不得进入模型输入或评分者输入包。
