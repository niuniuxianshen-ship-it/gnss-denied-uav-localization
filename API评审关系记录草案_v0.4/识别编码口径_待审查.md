## 四、整理后的待审查口径

### 4.1 识别层与最终判断分开

本口径只记录评审回答怎样识别比较，不改目标错误定义、原批次统计及最终“有错误／未发现本错误／未评／不适用”四种状态。识别层的1、0、“无法确认”“跳过”等不能替换最终判断。比较识别正确不等于比较有充分依据；识别漏失已确认也不自动证明原定位正文有目标错误。

以一份评审回答为汇总单位。下一轮运行前，需为每类登记适用材料、需核对的参照关系、原句与范围；本草案尚未执行这一步，不假定下一轮数量已固定。原文参照对象本就未明确时，参照记录也写“未明确”，不替评审补配候选。

### 4.2 五类记录的适用与证据

| 记录项 | 采用条件及所需证据 | 关系层记录与去向 |
| --- | --- | --- |
| 明确漏识别比较 | 参照正文存在明确比较，回答明确否认，或明确说该关系只有排序。保留原文比较句和回答否认句。“未发现本错误”本身不证明漏识别。 | 确认漏识别记1；有足够回答证据确认已识别该关系记0。只未提及、泛泛概述不能直接记1，所需信息不明转“无法确认”。 |
| 方向或比较对象识别错误 | 回答已表达比较，但双方或支持／削弱方向与参照不符；同时保留原句与回答对应句。未说清不能直接判错。 | 明确错记1；对象和方向均有证据确认未错才记0。信息不清记“无法确认”。同一关系已记漏识别时统一写“跳过：该关系已记漏识别，按互斥规则处理”，不得填0。 |
| 仅排序被误识别为比较 | 参照材料只有候选顺序，回答据此补出相对支持或削弱。保留排序原句与回答补出的关系。 | 确认误识别记1；有证据确认未发生记0；信息不足记“无法确认”。本来有明确比较的材料不属于本类固定适用组，记“不适用”，不是运行后因回答好坏排除。 |
| 回答不足以确认 | 回答可读，但泛称比较、只报最终状态，或不能核对关键对象、方向、原句对应。指出已确认部分与具体未确认关系。 | 作为辅助事件，每份有此情况记1，否则有证据确认未发生记0；受影响的错误类记“无法确认”。不能抹去其他关系已确认的错误，也不把明确否认一律降格为含糊。 |
| 格式缺失或技术问题 | 按各版本实际要求检查字段；空输出、明确截断、读取／运行失败须有证据。格式与技术分别记录，旧版没新增字段不算格式缺失，引文内容不相关也不自动算格式缺失。 | 格式、技术各以每份最多1次记录；没有重查技术时写“本轮未重新核查”，不得填0或声称通过。技术阻断的关键关系记“无法确认：技术原因”，另保留技术缺失标记，不当成漏识别。其余仍可判断的关系照常编码。 |

### 4.3 回答层汇总与带原因的跳过

对每一种识别错误类，先保存逐关系结果，再按以下规则汇总到回答层；不按单个已看关系推断全文：

1. 某类任一参照关系确认出错，该类记1；其他未明或跳过的关系仍保留在明细中。
2. 全部预先登记的适用参照关系均能确认未发生该类错误，才记0。只核对了一条、未看完其他关系，不能据此给全文0。
3. 没有确认错误，但仍有关键关系不明，该类记“无法确认”，记录具体关系及原因；技术原因另列标记。
4. 没有确认错误，也没有待判断关系，但存在按互斥规则跳过的关系，回答层记“跳过”并说明全部或部分跳过及原因，不填0。若同时有其他关键关系无法确认，按第3条汇总，仍保留跳过明细；若已有确认错误，按第1条记1并保留跳过明细。
5. 原文不属于该类运行前固定的适用材料范围，记“不适用”。不得把运行后“无法确认”“技术缺失”或“跳过”改写成事前不适用。

前三项是识别错误类；“回答不足以确认”和格式／技术为辅助记录。不同类可并存，不把各类数量直接相加作为不重复总错误份数。

### 4.4 固定适用材料数与可判子集分开

下一轮首先展示运行前固定的各类适用材料数及对应材料编号：漏识别和方向／对象错误以已标定存在比较的材料为适用组；仅排序误识别以已标定只有排序的材料为适用组；回答不足及格式／技术监测覆盖计划材料。需核对哪些关系也须在运行前登记。

固定适用材料数不会因回答无法确认、技术缺失、互斥跳过或输出格式缺失而缩小。每类至少同时列出：固定适用材料数、明确错误数、无法确认数、技术缺失数，以及带原因的跳过数；格式问题及技术未重新核查情况另列，不隐去。应能按材料编号追溯各自去向。

“无法确认不进入可判分母”仅适用于另列的可判子集：该类回答层为1或0的材料。可判子集排除了哪些材料、因何排除，必须写清；跳过不能当0纳入可判子集，也不能从固定适用数中消失。不能只报可判子集比例或以分母变小声称改进。

技术缺失为单独的技术标记，可与回答层“无法确认”或已确认错误并存；若发生重叠，列明交集材料编号，不将两种计数相加当不同材料总数。格式／技术辅助记录也不替换内容编码。“本轮未重新核查”表示检查覆盖尚未确认，不等于技术缺失已证实，更不等于0。

本次不填写下一轮虚构数量，不计算识别指标或正式E/D，不改变原三图批次的目标错误分母。
